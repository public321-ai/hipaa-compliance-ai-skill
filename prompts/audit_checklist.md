# HIPAA Audit Checklist

## Administrative Safeguards
- [ ] Risk analysis conducted annually
- [ ] Risk management plan implemented
- [ ] Sanction policy enforced
- [ ] Security officer assigned
- [ ] Workforce clearance procedures
- [ ] Termination access revocation < 24 hours
- [ ] Security training completed annually
- [ ] Incident response plan tested
- [ ] Contingency plan (data backup, disaster recovery, emergency mode)
- [ ] Business associate agreements current

## Physical Safeguards
- [ ] Facility access logs maintained
- [ ] Workstation security policies enforced
- [ ] Media disposal procedures (NIST 800-88)
- [ ] Device inventory current

## Technical Safeguards
- [ ] Unique user IDs assigned
- [ ] Role-based access controls implemented
- [ ] Automatic logoff configured (15 min)
- [ ] Audit logs enabled and reviewed
- [ ] Integrity controls (checksums) on ePHI
- [ ] Person/entity authentication (MFA where possible)
- [ ] Encryption in transit (TLS 1.2+)
- [ ] Encryption at rest (AES-256)

## Privacy Rule
- [ ] NPP posted and acknowledged
- [ ] BAAs executed
- [ ] Minimum necessary enforced
- [ ] Individual rights requests tracked
- [ ] Accounting of disclosures available

## Documentation
- [ ] Policies dated and signed
- [ ] Training records retained 6 years
- [ ] Audit logs retained 6 years
- [ ] Risk analysis retained 6 years
